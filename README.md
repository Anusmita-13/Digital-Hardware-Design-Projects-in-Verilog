🎯 **Verilog Digital Design Projects**

This repository documents a set of digital logic and RTL design projects that I have designed, implemented, and verified using Verilog HDL. The work demonstrates my hands-on experience in building fundamental digital circuits, writing synthesizable RTL, and validating functionality through structured testbenches and simulation workflows.

The projects focus on applying core digital design concepts, understanding different modeling styles, and gaining practical exposure to simulation and waveform analysis using industry-relevant tools.

🔧 **Tools Used**

•	Language: Verilog HDL (IEEE Std 1364-2001)

•	Simulator: EDA Playground (e.g., Icarus Verilog, Synopsys VCS, etc.)

•	Waveform Viewer: GTKWave (where applicable)

🧩 **Included Design Modules**

The repository currently features a range of digital designs, such as:

🔹**Basic Logic Modules**

•	NOT, AND, OR, NAND, NOR, XOR, XNOR

🔹 **Combinational Circuits**

•	Half Adder & Full Adder

•	Multiplexers (2×1, 4×1, 8×1)

🔹 **Sequential Elements**

•	Flip-Flops: SR, JK, D, T

🔹 **Finite State Machines**

•	110100 Sequence Detector FSM

🔹 **Modeling Styles**

•	Behavioral, Dataflow, and Gate-Level implementations
